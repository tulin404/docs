# Introdução

Bem-vindo à documentação da **My Library**.

Esta biblioteca ajuda você a organizar tarefas em aplicações JavaScript e TypeScript.

## Requisitos

Antes de começar, verifique se você tem:

- Node.js 22 ou superior
- npm, pnpm ou Yarn
- Conhecimentos básicos de JavaScript

## Instalação

Instale o pacote usando seu gerenciador preferido:

```bash
npm install my-library
```

Ou, se estiver usando pnpm:

```bash
pnpm add my-library
```

## Primeiro exemplo

Importe a função e utilize-a no seu código:

```ts
import { createTask } from "my-library";

const task = createTask({
  title: "Ler a documentação",
});

console.log(task);
```
